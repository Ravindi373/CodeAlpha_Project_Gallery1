# Gallery

A responsive image gallery showcasing beautiful photographs. Built with HTML, CSS, and JavaScript.

## Features

- Responsive design that works on all devices
- Smooth image transitions
- Navigation through thumbnails and arrow buttons
- Keyboard navigation support
- Automatic slideshow with hover pause
- Touch-friendly interface

## Live Demo

You can view the live demo at: [Gallery Demo](https://ravindi373.github.io/CodeAlpha_Project_Gallery1/)

## Setup

1. Clone the repository:
```bash
git clone https://github.com/[your-github-username]/gallery.git
```

2. Open `index.html` in your browser to view locally

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
